Before We Start 📋

Step 1: Install Node.js

✓ Version 18.x or higher

→ node --version

Step 2: Install Nx CLI

→ npm install -g nx@latest

Step 3: Verify Installation

→ nx --version

You're ready to go! 🎉

Step 1: Initialize Workspace 🏗️

npx create-nx-workspace@latest my-workspace

Choose these options:

  • ✓ Preset: Angular Monorepo
  • ✓ App name: your-app-name
  • ✓ Stylesheet: SCSS (recommended)
  • ✓ Nx Cloud: Yes (for caching)

Wait 2-3 minutes... ⏱️

Your Workspace Structure 📁

my-workspace/
├── apps/ → Your applications
├── libs/ → Shared libraries
├── tools/ → Custom scripts
├── nx.json → Nx config
└── package.json → Dependencies

Key Principle:

Apps consume libraries
Libraries never import apps

Step 2: Create Applications 📱

Generate a new Angular app:

nx g @nx/angular:app admin-portal

With routing & standalone:

nx g @nx/angular:app customer-app \
--routing --standalone

Serve it:

nx serve admin-portal

Open: http://localhost:4200 🌐

Step 3: Build Shared Libraries 📚

UI Components:

nx g @nx/angular:library ui-components \
--directory=shared

Data Access Services:

nx g @nx/angular:library data-access \
--directory=shared

Utilities:

nx g @nx/angular:library utils \
--directory=shared --buildable

One library = One purpose ✨

Organize Your Libraries 🗂️

🎨 UI Libraries

→ Buttons, cards, forms, layouts

📡 Data Access

→ API calls, state management

🔧 Utils

→ Helper functions, validators

🎭 Feature Libraries

→ Smart components with logic

Pro Tip: Use naming pattern
scope-type-name

Step 4: Create Components 🎨

Component in library:

nx g @nx/angular:component button \
--project=shared-ui-components \
--export

Standalone component:

nx g @nx/angular:component card \
--project=shared-ui-components \
--standalone --export

Service in library:

nx g @nx/angular:service auth \
--project=shared-data-access

Step 6: Use Your Libraries 🔗

Nx auto-configures import paths:

Before:

import { Button } from
'../../../libs/shared/ui-components'

After:

import { ButtonComponent } from
'@my-workspace/shared/ui-components'

Clean imports = Happy developers 😊

Visualize Your Architecture 📊

See all project connections:

nx graph

View only affected projects:

nx graph --affected

Benefits:

  • ✓ Understand relationships
  • ✓ Catch circular dependencies
  • ✓ Plan refactoring safely

Knowledge is power! 💪

Step 7: Build Like a Pro 🚀

Build specific app:

nx build my-app

Run tests:

nx test my-app

Test everything:

nx test --all

Only test changes:

nx affected:test

Build only affected:

nx affected:build

Save 40% of build time! ⚡

Pro Tips for Success 💡

  • 1️⃣ Use clear naming
    scope-type-name format
  • 2️⃣ Keep libraries focused
    One responsibility per library
  • 3️⃣ Set project boundaries
    Use tags to enforce rules
  • 4️⃣ Install Nx Console
    VSCode extension = visual power
  • 5️⃣ Enable Nx Cloud
    Free distributed caching
